# Contributing

CogitoEngine runs on evidence, not enthusiasm.

**Bring a transcript.** Run a flow on a task you know cold, then open an
issue with the YAML, the task, and the full step outputs. Failures are more
useful than successes.

**Challenge the assembly model.** The three-layer model (Agent / Flow /
Assembly) is a v0 proposal. If it is wrong, prove it with a flow that cannot
be expressed in it.

**Rules carried over from the Forge:**

- Refusal of a bad premise is a first-class output.
- Specified is not demonstrated.
- Every claim about what a flow produced carries its transcript.

Keep PRs small. One flow, one fix, one unknown closed — with evidence.
